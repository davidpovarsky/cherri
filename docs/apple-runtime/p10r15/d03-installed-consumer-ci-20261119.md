# Installed documentation consumer CI gate: verified preparation

Implementation: `bb2759778ff8f1365e0fcb360e09c541554489d7`.

The manual `P10R15 Installed Documentation Consumers` workflow closes an executable gap: the existing installed Skill/public website collector had no CI job that consumed its original absolute artifact references with the production Go intake in the same POSIX workspace. The new job reuses that collector, package verifier and production intake. It changes no pins, deployed files, app code, or acceptance requirements.

## Actual verification

The implementation checkout remained clean before and after the replay. Seven Python control methods passed in 18.041 seconds; they exercise actual temporary Git repositories, modeled API identities and unsafe archive inputs. The immutable D03 contract still requires docs plus integration; an accepted docs record is explicitly incomplete. The controls use synthetic collector fixtures and are not live D03 evidence.

The preparer then ran from an ordinary clean checkout of the exact implementation against actual public GitHub metadata and the original authorized artifact bytes. It passed in 2.118 seconds. Its exact two JSON members, current expiry, original digest, run/source bindings and successful build/deploy jobs were verified. Original ZIP and metadata bytes are retained.

## Gate behavior and limits

Dispatch supplies the Pages run ID and Base64 of that original public ZIP. Input is bounded to 32 KiB; unverified bytes stay in a non-published quarantine directory. Only an exact two-member regular-file archive passes. Duplicate, traversing, linked, oversized, malformed, stale, borrowed or mismatched input fails closed. The job installs exact committed Skill bytes outside its source tree, then executes the existing eight installed searches and seven live public routes. It runs the actual Go intake in that same workspace; it does not rewrite artifact paths or invent an app receipt.

The checked-in consumer compiler pin remains `b97ae752205f1e747b6c98ff7511f3484dd53bc2`. Preparing this gate does not validate a future compiler-pin update. The new live CI job, installed/public collector and independent app integration have not yet executed on this source. D03 and final179 remain incomplete.
