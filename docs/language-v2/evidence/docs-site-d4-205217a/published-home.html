Write Apple Shortcuts with Cherri V2.

The active authoring guide for the davidpovarsky fork of Cherri.

Start with the V2 guide Find an action

Your first program

Save this example as a .cherri file:

let name = "Cherri"
show(f"Hello from {name}!")

The default compiler language is V2. The examples on this site are checked against an immutable compiler revision before publication.

Historical reference

The reference archive retains upstream material and previously migrated pages. It is outside this site’s default search and navigation. Use the current guide above when writing new code. Legacy compilation requires an explicit --lang=legacy selection.

Cherri originated in the upstream project. This site documents the fork; upstream releases and tools may use different syntax.
