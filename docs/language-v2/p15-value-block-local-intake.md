# Distinct value-block and loop-result local intake

This source producer covers F04, RP23 and BRG14 separately. Its expected action
graphs are authored independently of the compiler output; only canonical native
UUID and grouping identifiers are accepted as alpha names. Original plist integer,
real and Boolean types remain distinct. Complete action order, branch ancestry,
result producers, consumers, return boundaries and unused main output are compared.

## Scope

- **F04:** five supported scalar/for-item sources and two actual target-boundary
  diagnostics are observations only. A nested List or Optional loop element has
  no verified one-element/no-flatten/presence transport in the current compiler.
  The complete scenario stays **NOT_RUN**, emits no formal acceptance record and
  receives no unit/native tier credit from these narrower observations.
- **RP23:** an independent joined if/menu/zero-repeat/multiple-repeat/for scenario
  checks static types and the complete local graph. Missing, illegal and
  overwritten explicit yields are source-bound diagnostic controls. Its immutable
  minimum is unit plus native; a passing exact replay can satisfy that local
  requirement without satisfying F04 or any Apple obligation.
- **BRG14:** a separate joined source plus six complete main/child return sources
  check partial early return, both-return branches, a zero-iteration return,
  bare return, function dispatch and parent continuation, and exact bare Nothing
  on implicit main fallthrough. The required Apple runtime tier stays pending.
  Actual menu selection, collected element count, runtime absence, frame exit
  and rendered values are not inferred from serialized structure.

All-implicit native-last-action value blocks retain their existing AnyContent
boundary. A missing explicit yield in one branch of an otherwise explicitly
yielded value block is diagnosed. The tests do not silently redefine implicit
native behavior or treat the target rejection of nested List/Optional as a
successful implementation of that transport.

## Evidence boundary

Each distinct process must run the exact clean implementation SHA. The fixed
event inventories are 47 F04, 58 RP23 and 97 BRG14 events, including parents.
The reviewed source witness list has 111 paths; the shared caps remain 128 paths,
4 MiB per blob, 16 MiB total and 15 seconds. Fixed source-list digest, original
Go JSON events, stderr, process timestamps, command, exit status and every source
digest are revalidated at intake. No related requirement, old loop trace or
generic runControl marker supplies a missing producer.

F04 retains a separate cherri.value-loop-facets/v1 observation with all formal
completion flags false. Its actual artifact tuple is validated, but even those
valid originals cannot be relabeled as complete F04 evidence. Failed subset
execution stays visible as FAILED_SUPPORTED_FACET while the unexecuted complete
contract remains NOT_RUN.

The default nested Go budget is the existing three minutes plus one minute of
process overhead per scenario. This source change does not increase a process,
source, output or aggregate budget. An actual replay and independent proof packet
are required before any execution or acceptance claim.
