## Native substitution boundary

native_signed_caller_input_owner.py inherits the existing execution, process capture, device selection, XCTest, source closure and cancellation-safe finish. It adds only an explicit signing selection and signature-consumption step. The selection binds the exact canonical native plan and a separate pinned directory of signing originals.

Admission checks the original owner, distinct signer build and bytes, packet/compiler identity, actual process start/end/exit, complete streams and reaped/absent group, exact argv and bounds, original source/plist bytes, provenance and signed digest. It preserves an aggregate failure while admitting only the specifically successful original case. The failed initial companion cannot be selected. The separately successful companion must retain its exact prior HTTP 502 evidence.

All signing originals are copied into the native run directory and read back before import. Their pins are retained in the final native result. There is no additional signing subprocess. The existing native finalizer still rechecks the unsigned packet, signed artifact, complete source and current built products.
