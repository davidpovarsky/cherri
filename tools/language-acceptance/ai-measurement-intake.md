# Source-bound AI measurement intake

The formal runner keeps three different states: no configured real bundle is AI_EVAL_NOT_RUN; an explicitly configured but incomplete or rejected bundle fails intake; twelve adjudicated original outcomes can supply evaluation evidence. A refusal, truncation or semantic task failure remains a measured failure in its original six-per-arm denominator. Transport/protocol errors and unsupported graphs remain incomplete.

AI01 accepts only the dedicated canonical intake producer. RP50 separately requires its actual fixed fifteen-test Python harness child and measured external tier. BRG32 retains its existing independent obligation-accounting/install/configuration producer. None inherits another requirement's pass.

## Independent authenticated inputs

Only the authenticated root/operator channel supplies the following environment configuration. Values must come from the actual connector/API rereads and retained originals, never from a field in the evaluation report or sealed bundle.

| Variable | Meaning |
|---|---|
| CHERRI_AI_EVALUATION_BUNDLE | Absolute path to the sealed evaluation bundle and all retained original outcomes |
| CHERRI_AI_EVALUATION_SOURCE_ROOT | Exact clean checkout containing the frozen producer; defaults to this repository |
| CHERRI_AI_EVALUATION_ASANA_BEFORE | Original authenticated Asana response retained outside the bundle before the first provider call |
| CHERRI_AI_EVALUATION_ASANA_BEFORE_SHA256 | Independently pinned digest of those exact raw bytes |
| CHERRI_AI_EVALUATION_ASANA_BEFORE_OBSERVED_UTC | Root-observed UTC of that authenticated reread |
| CHERRI_AI_EVALUATION_ASANA_AFTER | Original authenticated response retained separately after all outcomes |
| CHERRI_AI_EVALUATION_ASANA_AFTER_SHA256 | Independently pinned digest of the final exact raw bytes |
| CHERRI_AI_EVALUATION_ASANA_AFTER_OBSERVED_UTC | Root-observed UTC of the final reread |
| CHERRI_AI_EVALUATION_ANCHOR_STORY_ID | Exact root-verified story identity on task1220432417414104 |
| CHERRI_AI_EVALUATION_ANCHOR_TEXT_SHA256 | Exact root-verified body digest of the frozen commitment |

The two reads must identify the same unchanged story and commitment. Their independently observed times must strictly bracket the interval recomputed from original provider/validator receipts. The story's server-created timestamp must precede the before-read observation, and the after-read observation cannot be in the future relative to actual intake.

This offline Go/Python verifier cannot authenticate arbitrary caller-written JSON as a server response. Its reports preserve that boundary explicitly. A field named verified, a summary's claimed hash or an anchor copied from inside the bundle does not establish independent authentication.

## Actual execution and revalidation

The runner invokes the frozen canonical Python CLI once for each independently pinned Asana original. It checks exact clean Git source before/after, bounded immutable source witnesses, command vectors, raw stdout/stderr, the original process interval and the safe output summary. The two summaries must contain the same twelve observations and anchor, apart from their independently pinned response hashes.

Manifest intake reads the original process/source/summary artifacts and invokes the canonical read-only verifier again against the independently selected bundle and Asana originals. A standalone PASS JSON cannot satisfy this operation. Revalidation reads/recomputes existing originals; it does not call a provider, generate another response or rebuild the compiler.

The current runner's implementation SHA must equal the bundle's frozen implementation SHA. The compiler source/binary is separately pinned by the canonical Python producer. Freeze all source corrections and the calibrated compiler before preparing the real bundle. The Go adapter does not hardcode an obsolete final implementation SHA or copy a historical score.

The new intake process is bounded to two minutes per canonical invocation. Existing RP50 harness selection, fifteen Python controls, three-minute Go test and four-minute process budget remain unchanged. The source witness reader retains its128-file,4MiB-per-file,16MiB-total and15-second limits.

## Publication boundary and verification

Retain the full bundle, signing key, seed, raw Asana responses and original provider requests/responses privately on the authorized host. Public evidence contains only the safe intake summary, source/process metadata, hashes, minimal anchor identity and scoped counts. Do not archive the entire bundle into the repository or CI artifacts.

The measured scope is fresh exact instances of six existing public patterns. Both Apple runtime and unseen-pattern provenance remain false. The Python report does not grant global acceptance; the formal runner can credit only the applicable evaluation tier after independent validation. Other179 requirements, final CI and release closure remain separate.

Go shape fixtures are explicitly synthetic validator controls. They never produce actual model evidence. A complete actual positive measurement requires the root-authenticated originals and canonical revalidation described above.
